# S3 Client — Yandex Cloud Storage

Небольшое веб-приложение на FastAPI для работы с S3-совместимыми бакетами и объектами с помощью IAM-токена. Проект ориентирован на Yandex Cloud Object Storage.

Приложение предоставляет HTTP API для просмотра, создания и удаления бакетов, загрузки, скачивания и удаления объектов, а также получения основной статистики по бакету.

---

## Возможности

- Просмотр списка бакетов и объектов
- Создание и удаление бакетов (в том числе принудительное удаление непустых бакетов)
- Загрузка, скачивание и удаление объектов
- Веб-интерфейс для управления бакетами и объектами
- Небольшое приложение на Python и FastAPI, которое можно запустить локально или в Docker

---

## Структура проекта

- `app/` — основной пакет приложения
  - `main.py` — точка входа FastAPI-приложения
  - `s3_client.py` — минимальная реализация клиента S3 с использованием IAM-токена
  - `gen-and-exchange-jwt-to-iam.py` — получение IAM-токена для сервисного аккаунта и запись его в `.env`
  - `authorized_key.json` — файл ключа сервисного аккаунта, необходимый скрипту для получения IAM-токена
  - `routes/` — маршруты API для бакетов и объектов
  - `models.py` — модели запросов и ответов Pydantic и их валидация
  - `config.py` — загрузка конфигурации и переменных окружения
  - `static/` — статические файлы веб-интерфейса
    - `index.html` — главная страница управления бакетами и объектами
- `Dockerfile` — описание образа контейнера
- `docker-compose.yml` — конфигурация для запуска сервиса через Docker Compose
- `requirements.txt` — зависимости Python

## Быстрый старт: Docker

Запустите сервис с помощью Docker Compose:

```bash
docker-compose up -d --build
```

Перед запуском убедитесь, что `app/.env` настроен и доступен контейнеру согласно `docker-compose.yml`, либо передайте `IAM_TOKEN` через переменные окружения контейнера.

---

## Конфигурация

Приложение загружает настройки из `app/.env` с помощью `python-dotenv`:

- `IAM_TOKEN` — обязательный IAM-токен Yandex Cloud, используемый для запросов к хранилищу.
- `S3_ENDPOINT_URL` — адрес S3-совместимого сервиса. По умолчанию: `https://storage.yandexcloud.net`.

Настройки загружаются в `app/config.py`.

Если у вас настроен файл ключа сервисного аккаунта `app/authorized_key.json`, IAM-токен можно получить автоматически:

   ```bash
   python app/gen-and-exchange-jwt-to-iam.py
   ```

   Скрипт формирует JWT на основе ключа, обменивает его на IAM-токен Yandex Cloud и сохраняет токен в `app/.env` как `IAM_TOKEN`. Если в `.env` уже есть такая переменная, скрипт заменит её значение, сохранив остальные настройки. Запустите скрипт повторно, когда потребуется обновить токен, затем запустите приложение.

   **Важно:** `authorized_key.json` содержит закрытый ключ сервисного аккаунта. Не публикуйте его, не добавляйте в репозиторий и ограничьте доступ к файлу.

## API

Базовый путь: `/`.

- `GET /health` — проверка работоспособности сервиса
- `GET /buckets` — список бакетов
- `POST /buckets` — создание бакета
  - Тело запроса (JSON): `{ "name": "bucket-name" }`
- `GET /buckets/{bucket_name}` — сведения о бакете и статистика объектов
- `DELETE /buckets/{bucket_name}?force=true` — удаление бакета; при `force=true` сначала удаляются объекты
- `GET /buckets/{bucket_name}/objects` — список объектов; поддерживается параметр `prefix`
- `POST /buckets/{bucket_name}/objects` — загрузка объекта через `multipart/form-data` с полем `file` и необязательным полем `key`
- `GET /buckets/{bucket_name}/objects/{object_key}` — просмотр или скачивание объекта; `download=true` включает режим скачивания
- `DELETE /buckets/{bucket_name}/objects/{object_key}` — удаление объекта

Полная схема доступна в интерактивной документации по адресу `/docs` после запуска приложения.

## Веб-интерфейс

После запуска приложения откройте http://<адрес-сервера>:8000. Главная страница загружается из `app/static/index.html`.

В интерфейсе можно:

- просматривать, создавать, выбирать и удалять бакеты;
- просматривать содержимое выбранного бакета и искать объекты по имени;
- загружать файлы размером до 50 МБ, при необходимости задавая собственный ключ объекта;
- просматривать, скачивать и удалять объекты.

Статические файлы в `app/static/` содержат клиентскую часть приложения. Интерфейс обращается к API этого же сервиса, а маршруты и обработка операций находятся в `app/routes/`.
